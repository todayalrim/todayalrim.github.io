1. 서비스 개요

"autoshorts"는 '오늘 알려드림' 채널 운영자가 본인 소유의 유튜브, 인스타그램, 틱톡 계정에 직접 제작한 영상을 업로드하기 위해 사용하는 개인용 프로그램입니다. 외부 이용자에게 제공되는 서비스가 아닙니다.

2. 수집하는 정보

본 프로그램은 운영자 본인의 계정에 대한 접근 권한(OAuth 토큰)만 사용하며, 그 외 어떠한 이용자의 개인정보도 수집, 저장, 공유하지 않습니다. 토큰은 운영자의 개인 컴퓨터에만 저장됩니다.

3. YouTube API 서비스 이용

본 프로그램은 YouTube API 서비스를 사용해 영상을 업로드합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

4. 권한 철회

부여한 접근 권한은 언제든지 Google 계정 보안 설정에서 철회할 수 있습니다.
